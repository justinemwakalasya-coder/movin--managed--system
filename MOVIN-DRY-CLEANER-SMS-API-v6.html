📱 Tuma Ujumbe kwa Mteja

Mfumo hubadilisha {JINA} na {ODA} automatically kwa mteja aliyechaguliwa.

📣 Tuma kwa Wote

Kwa HTML ya simu pekee, usalama wa Android haukuruhusu tovuti kutuma SMS kimya kimya bila ruhusa. Kitufe hiki hufungua programu ya SMS ikiwa simu yako inaruhusu; kwa kutuma SMS automatically bila kubonyeza Send, mfumo unahitaji SMS Gateway/API.

⚙️ Mipangilio ya SMS ya Moja kwa Moja (API)

Tumia TextBee (bure — hakuna ada ya usajili, unatumia simu yako ya Android + laini yako mwenyewe kutuma SMS): (1) Sakinisha app ya TextBee kwenye simu ya Android, (2) Fungua akaunti bure kwenye textbee.dev, (3) Sajili kifaa (device) na upate API Key + Device ID, (4) Weka hapa chini na uwashe.
